## Objective

Prepare and publish MQL5 CodeGraph v0.3.0 as a public beta only after token/API, dependency, package,
hosted-CI, and repository-security gates pass.

- Known constraints: the repository started private; the authoritative PDFs, generated corpus, Graphify

## Decisions

- Provider credentials are ambient only at the final explicitly authorized Graphify extraction process;
  they are not inherited by version probing or unrelated backends and do not become command arguments,
  manifests, structured errors, or lifecycle records.
- Graphify remains an operator-selected executable and is not represented as a sandboxed component.
- GitHub visibility, secret scanning, push protection, dependency alerts, private vulnerability
  reporting, hosted CI, and public artifact installation are release gates rather than optimistic
  documentation claims.
- A CodeQL alert is a release blocker until its dataflow is removed or an evidence-backed accepted risk
  is documented; alerts are not dismissed merely to make the gate green.

## Risks and unresolved questions

- The external Graphify executable can access resources permitted to its OS identity. Environment
  filtering reduces ambient credential exposure but is not process or filesystem sandboxing.
- GitHub Actions reports that the pinned `actions/upload-artifact` release targets deprecated Node.js 20
  and currently forces Node.js 24. The job passes, but the pin should move to a natively supported runtime.
- GitHub reports the v0.3.0 Release as mutable. The annotated tag and published digests are verified, but
  immutable releases and artifact attestations remain future supply-chain hardening.

## Next objective

Define the v0.3.1 supply-chain hardening change that upgrades the artifact-upload runtime and adds
verifiable artifact provenance before the next release.
